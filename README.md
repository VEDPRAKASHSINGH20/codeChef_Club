# CodeCrew Club Events

Responsive club event website (HTML, CSS, JavaScript, no build step).

## Run
Open `index.html` in a browser.

## Pages
- Home: intro, featured event with countdown, upcoming events
- Events: search, category filter, registration form
- Admin (`#/admin`, password `admin123`): add/edit/delete events, view and search registrations

## Notes
Data is stored in the browser (localStorage). A backend and real admin authentication would be needed for production use.
